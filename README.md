---

## 📌 项目简介

本机器人专为 Robocon 2026 排球赛项设计，具备以下能力：

- **全向移动底盘**：等边三角形电机布局 + VESC 电调驱动 5055 电机，灵活稳定。
- **自动打滑矫正**：引入 JY61P 陀螺仪，解决快速侧移时的偏航问题。
- **三气缸击球装置**：替代初代双电机方案，力度可调，响应迅速。
- **远距离遥控**：ESP32-S3 遥控器 + HC12 无线模块，适应竞赛场地。
- **实时操作系统**：FreeRTOS 任务调度，多任务并行执行。

项目代码完全开源，提供 STM32CubeIDE / Keil 工程文件，可直接编译烧录。

## ✨ 主要特性

| 模块             | 实现方式/部件                                      | 关键参数/说明                              |
| ---------------- | -------------------------------------------------- | ------------------------------------------ |
| **主控**         | STM32F407VET6                                      | Cortex-M4 @ 168MHz，丰富外设               |
| **底盘电机**     | 5055 无刷电机 ×3                                   | VESC 电调驱动，等边三角形布局              |
| **电机驱动**     | VESC 电调（CAN 总线控制）                          | 上位机电流环：Kp=0.1，Ki=200.0             |
| **姿态矫正**     | JY61 陀螺仪                                        | 角速度 + 角度反馈，打滑动态补偿             |
| **击球装置**     | 三气缸控制（替代灵足04）                           | 力度可调，时序控制，自动回球               |
| **遥控系统**     | ESP32-S3 遥控器 + E32 无线模块                    | 2.4GHz，距离 ≥ 200m（视距）                |
| **任务调度**     | FreeRTOS v2                                     | 多任务：底盘控制、击球、通信、监控         |
| **通信接口**     | CAN（VESC），USART（遥控器 + 调试），GPIO（气缸）  | CAN 波特率 500kbps，串口 115200            |

## 🧠 软件架构

### 模块功能说明表

| 模块             | 文件                       | 核心职责                                                     |
| ---------------- | -------------------------- | ------------------------------------------------------------ |
| **系统启动**     | `main.c` → `freertos.c` → `Task_Init.c` | 初始化 HAL，创建 FreeRTOS 任务，启动调度器                   |
| **底盘控制**     | `chassis.c`                | 全向移动运动学解算（等边三角形布局），遥控指令解析，力矩环控制，集成 JY61 打滑矫正 |
| **击球装置**     | `hitball.c`                | 三气缸时序控制，击球力度调节，自动回球逻辑                   |
| **遥控通信**     | `My_list.c`, `comm.c`, `dataFrame0.c`, `data_poll.c`, `comm_stm32_hal_middle.c` | 与 ESP32-S3 遥控器的无线通信（HC12），指令接收、解析、校验    |
| **轨迹平滑**     | `step.c`（原配合 `RobStride.c`） | 三次多项式算法，用于电机转速平滑过渡（当前保留，可供后续扩展） |
| **CAN 驱动**     | `CANDrive.c`               | VESC 电调的 CAN 总线通信，速度/电流控制指令下发，状态读取     |
